# CampusNest Malawi 🇲🇼

> **Verified Off-Campus Student Accommodation Finder for Malawian Universities**

CampusNest Malawi is a purpose-built web platform designed for tertiary students across Malawi—including UNIMA (Chancellor College), MUBAS (Polytechnic), MUST, LUANAR (Bunda), KUHeS, MZUNI, and DMI St. John the Baptist University (Mangochi). It connects students directly with verified landlords and trusted hostels with transparent Malawi Kwacha (MWK) rates, physical security audit badges, distance-to-gate metrics, and direct WhatsApp/call viewing appointments.

---

## 🌟 Key Features

- **University Campus Explorer**: Browse dedicated hostels and rooms tailored to each university:
  - UNIMA (Zomba — Chikanda, Chirunga)
  - MUBAS (Blantyre — Kanjedza, Chichiri)
  - MUST (Thyolo — Goliati)
  - LUANAR (Lilongwe — Bunda Campus)
  - KUHeS (Blantyre — QECH / Mahatma Gandhi)
  - MZUNI (Mzuzu — Luwinga)
  - DMI St. John the Baptist University (Mangochi Boma)
- **Authentic Photography & Host Data**: Real campus landmarks and room photography.
- **Physical Verification Badges**: Verified land ownership, NRB National ID check, water reliability audits (solar borehole / reserve tanks), and window security grilles.
- **Direct Landlord Contact & Viewing Appointments**: Instant WhatsApp chat integration (`+265991600735`) and free in-person viewing booking without advance deposit risks.
- **Malawi Phone & Email Authentication**: Malawian phone number format validation (`+265` / `088` / `099`) and fast Google Single Sign-On.
- **Low-Data Friendly Design**: Built with Warm Civic Modern styling, responsive mobile touch targets, and lightweight static assets.

---

## 🛠️ Tech Stack

- **Framework**: React 18 with Vite
- **Styling**: Tailwind CSS with custom design tokens (Warm Civic Modern, Emerald/Teal brand palette)
- **Icons**: Material Symbols Outlined & SVG brand assets
- **Form Management & Validation**: React Hook Form with Zod schemas
- **Routing**: React Router v6
- **Testing**: Vitest & React Testing Library (17 unit & integration tests)
- **Code Quality**: ESLint & Prettier

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Tessy-123/CumpsNest.git

# Navigate into project directory
cd CumpsNest

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be live at `http://localhost:3000`.

### Running Tests
```bash
npm run test
```

### Running Linter
```bash
npm run lint
```

### Building for Production
```bash
npm run build
```
